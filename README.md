# Mjølner Frontend Case

**Welcome to the Mjølner Frontend Case!**  
This is a simple evaluation exercise designed to give us a glimpse of your coding style and approach.

---

### **Purpose**
We want to see how you write and structure code. This isn’t about completing all tasks or building a perfect app—just spend **no more than 1 hour** working on this. If something doesn’t work or you get stuck, feel free to move on.

---

### **What You’ll Build**
A minimal React app showcasing a catalog. The theme of the catalog is entirely up to you! You can choose any dataset or topic that interests you, such as books, movies, animals, or anything else.

---

### **Requirements**
Here’s what we’d like to see in the app:

#### **List View**
- Display a list of items related to your chosen theme.
- Each list item should include:
  - A **name** or **title**.
  - An **image** or visual representation.

#### **Details View**
- Display additional details for a selected item, including:
  - A **name** or **title**.
  - An **image** or visual representation.
  - A **description** or additional details.

#### **Navigation**
- Clicking on an item in the List View should open the Details View.
- The details shown should match the item clicked.
- Provide a way to navigate back to the List View.

---

### **Data Source**
You can use mock data that you create yourself or fetch data from a free and open REST API. Some examples of APIs you could consider:
- [https://jsonplaceholder.typicode.com/](https://jsonplaceholder.typicode.com/)
- [https://www.thecocktaildb.com/api.php](https://www.thecocktaildb.com/api.php)
- [https://pokeapi.co/](https://pokeapi.co/)

---

### **Getting Started**
1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`

---

### **A Few Notes**
- Feel free to keep it simple! We’re interested in your code quality and approach, not the complexity of the app.
- Don’t stress about completing everything—focus on writing clean, understandable code for the parts you work on.

---

### **Good Luck!**
We look forward to seeing your code and discussing your approach during the interview. 😊
